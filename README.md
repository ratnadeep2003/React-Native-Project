# React Native Project

A React Native app built with Expo featuring multiple screens, a component library, and dynamic theme switching.

## Screens
- Home
- About
- Component Library
- Theme Settings

## Tech Stack
- React Native
- Expo
- React Navigation

## Run Locally

1. Clone the repo
```bash
   git clone https://github.com/ratnadeep2003/React-Native-Project.git
   cd React-Native-Project
```

2. Install dependencies
```bash
   npm install
```

3. Start the project
```bash
   npx expo start
```

4. Scan the QR code with **Expo Go** app on your phone
